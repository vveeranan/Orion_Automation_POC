# TC17083 - GroupKPIs_WhenListed_ShouldDistinguishEnabledFromDisabledKPIs

Release ORION 2025.2000.1 - RT-25957 (Group KPIs). Spec: tests/RT25957.spec.ts.

Categories: Regression, KPI, GroupKPIs, Administration, Claims

Setup (Setups/TC17083.cs): creates the group the test configures its KPIs on (Orion Worker Portal DLL: Groups.CreateGroup, read-or-create by name).

Steps in the test:

1. Log in to Orion.
2. Go to Administration > Groups, search for the group created by the setup and open it.
3. Open the Group KPIs tab.
4. Enable Claims Pending; leave Claims Worked disabled.
5. Verify the enabled KPI offers Disable (not Enable) and the disabled KPI offers Enable (not Disable).
6. Compare the class and computed styling (background, colour, opacity, border) of the two rows and verify they differ (soft assertion: the FRD only requires that they can be visually identified).

Notes:
- Test case wording follows the FRD; in the build Claim KPIs / CS KPIs are the Claims Processing KPIs / Customer Service KPIs headings, Period measured is Time Period, Style is Display Type (Three Bar Graph = Bar) and every change in the KPI editor is saved as it is made (no Save button).
- Shared helpers: utils/kpi.ts. After the test the user is taken out of the group again (afterEach), so the next test's ribbon only shows its own KPIs.
