# TC6286 - QC Orion - Create a New Member Ticket

Categories: Smoke, Member, Ticket

1. Log in to Orion.
2. Go to Customer Service > My Tickets and note the ticket count.
3. Click Add Ticket, then click Member Call. A new ticket is created and opens in the Open status.
4. Enter the caller and caller phone.
5. Search for the member created by the setup and select the match.
6. Go back to My Tickets and verify the new ticket is listed first (type Member, status Open, the caller, created by the logged-in user) with the count up by one.
