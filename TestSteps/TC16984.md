# TC16984 - TaskKPI_WhenUserOpensTile_ShouldShowApprovedKPIInformation

Release ORION 2025.2000.1 - RT:27053 (KPI ribbon and KPI configuration).

Categories: Regression, KPI, Ribbon, Information, CustomerService, Tickets

Setup (Setups/TC16984.cs): creates the group the test configures its KPIs on (Orion Worker Portal DLL: Groups.CreateGroup, read-or-create by name) and 3 tickets (Tickets.CreateTicket) as data for the Customer Service KPIs. The KPI configuration is stored per group, so every test works on its own group and the logged in user is assigned to it by the test.

Steps in the test:

1. Log in to Orion.
2. Go to Administration > Groups, search for the group created by the setup and open it.
3. On Group Assignments click the logged in user in the Users list to assign them to the group (a clean-up step takes them out again after the test).
4. Open the Group KPIs tab.
5. Enable Tickets Created if needed, select it and set Benchmark More, the benchmark value, Time Period Current Month, Display Type Ticker (each change is saved straight away).
6. Go to the Tickets page and click the Tickets Created tile.
7. Verify the KPI Information dialog has the title and the table rows Name, Description, Short Name, Group Name, Individual, Group Average, Benchmark, Style, Period Measured, in that order.
8. Verify the values: Name Tickets Created; Description "The number of tickets created for a configured period of time."; Short Name CS-CREA; Group Name the test group; Individual and Group Average numbers; Benchmark "> <value>"; Style Ticker; Period Measured Month.
9. Click the close button and verify the dialog closes and the tile is still shown.

Notes:
- The test cases are named "TaskKPI"; in the build under test the KPI feature has Claims Processing KPIs (Claims Queue ribbon) and Customer Service KPIs (Tickets ribbon), and My Tasks has no KPI ribbon. "Task" KPIs are therefore the Customer Service KPIs and "My Task" is the Tickets page.
- Shared helpers: utils/kpi.ts. After the test the user is taken out of the group again (afterEach), so the next test's ribbon only shows its own KPIs.
