# TC6290 - QC Orion - Create a New Queue Schedule

Categories: Smoke, Queue, Schedule, Administration

1. Log in to Orion.
2. Go to Administration > Queues.
3. Click Add New Schedule. The Queues Schedule page opens with an hourly trigger and no queues assigned.
4. Enter the schedule name and description. There is no Save button: the schedule saves automatically once both fields are filled (a name without a description is rejected), so the test waits for the successful save.
5. In the Queues list, select the queue created by the setup. It moves to Queue Assignment.
6. Click Back to Queues and verify the new schedule is listed in the Schedules panel with its Every hour trigger.
