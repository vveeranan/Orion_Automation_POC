# TC17094 - GroupKPIs_WhenDisabledKPIEnabledAgain_ShouldShowSavedConfigurationInEditor

Release ORION 2025.2000.1 - RT-25957 (Group KPIs). Spec: tests/RT25957.spec.ts.

Categories: Regression, KPI, GroupKPIs, Administration, Claims, Configuration

Setup (Setups/TC17094.cs): creates the group the test configures its KPIs on (Orion Worker Portal DLL: Groups.CreateGroup, read-or-create by name).

Steps in the test:

1. Log in to Orion.
2. Go to Administration > Groups, search for the group created by the setup and open it.
3. Open the Group KPIs tab.
4. Enable Claims Pending and set Benchmark More, the Benchmark value, Period measured (Time Period) and Style (Display Type); each change is saved as it is made. (More, value 7, Current Week, Ticker)
5. Disable the KPI and acknowledge the confirmation.
6. Enable the KPI again; verify it is enabled and not flagged "not configured!".
7. Select the KPI and verify the editor shows the saved configuration: More, 7 and Current Week (not empty fields).

Notes:
- Test case wording follows the FRD; in the build Claim KPIs / CS KPIs are the Claims Processing KPIs / Customer Service KPIs headings, Period measured is Time Period, Style is Display Type (Three Bar Graph = Bar) and every change in the KPI editor is saved as it is made (no Save button).
- Shared helpers: utils/kpi.ts. After the test the user is taken out of the group again (afterEach), so the next test's ribbon only shows its own KPIs.
