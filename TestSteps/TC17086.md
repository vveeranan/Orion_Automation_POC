# TC17086 - GroupKPIs_WhenDecimalBenchmarkValueEntered_ShouldRefuseValue

Release ORION 2025.2000.1 - RT-25957 (Group KPIs). Spec: tests/RT25957.spec.ts.

Categories: Regression, KPI, GroupKPIs, Administration, Claims, Negative

Setup (Setups/TC17086.cs): creates the group the test configures its KPIs on (Orion Worker Portal DLL: Groups.CreateGroup, read-or-create by name); test data: Benchmark value 5 and the decimal value 2.5.

Steps in the test:

1. Log in to Orion.
2. Go to Administration > Groups, search for the group created by the setup and open it.
3. Open the Group KPIs tab.
4. Enable Claims Pending, select it and set Benchmark More (the value field is editable after that).
5. Start recording the configuration requests, type the decimal value 2.5 in the Benchmark value and leave the field.
6. Verify no request saved the value 2.5 and the field no longer holds 2.5.
7. Enter the whole number 5 and verify it is saved and shown.

Notes:
- Test case wording follows the FRD; in the build Claim KPIs / CS KPIs are the Claims Processing KPIs / Customer Service KPIs headings, Period measured is Time Period, Style is Display Type (Three Bar Graph = Bar) and every change in the KPI editor is saved as it is made (no Save button).
- Shared helpers: utils/kpi.ts. After the test the user is taken out of the group again (afterEach), so the next test's ribbon only shows its own KPIs.
