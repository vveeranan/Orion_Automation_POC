# TC6297 - QC Orion - Open About Orion form

Categories: Smoke, AboutOrion

1. Log in to Orion.
2. Click the profile icon in the top right corner and select About Orion. The About Orion popup opens.
3. Verify the version shown for each component against the expected value:
   - Orion Worker Portal, Authorizations API, Claims API, Enums API, Members API, Notes API, Providers API, Referrals API and Storage API: the version reported by the Get-Orion-Services-Versions.ps1 script (the setup runs the script and records the QC section of its output).
   - Claims System: the latest QC system update in the QC database, shown as "<update> (QC_<yy>_<release>)", for example 2025.2000.0.00 (QC_25_2).
4. Close the popup.

Note: the script reads the Orion web server's install folder (C:\inetpub\wwwroot\Plexis Worker Portal - QC\bin). When that folder is not on the machine running the setup, the script is run unchanged on the services server through PowerShell remoting.
