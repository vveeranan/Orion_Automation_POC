# TC6288 - QC Orion - Create a New Group

Categories: Smoke, Group, Administration

1. Log in to Orion.
2. Go to Administration > Groups and note the group count.
3. Click Add Group. The Group dialog opens.
4. Enter the group name and description, then click Save.
5. Verify the dialog closes and the group count is up by one.
6. Search for the group and verify its name and description are listed.
