# TC17089 - GroupKPIs_WhenEditingKPI_ShouldOfferBarAndTickerStylesAndSaveEach

Release ORION 2025.2000.1 - RT-25957 (Group KPIs). Spec: tests/RT25957.spec.ts.

Categories: Regression, KPI, GroupKPIs, Administration, Claims, Configuration, Ribbon

Setup (Setups/TC17089.cs): creates the group the test configures its KPIs on (Orion Worker Portal DLL: Groups.CreateGroup, read-or-create by name).

Steps in the test:

1. Log in to Orion.
2. Go to Administration > Groups, search for the group created by the setup and open it.
3. On Group Assignments click the logged in user in the Users list to assign them to the group (an afterEach clean-up takes them out again).
4. Open the Group KPIs tab.
5. Enable Claims Pending and set Benchmark More, the value (3) and Current Day, without a Style.
6. Verify the Style (Display Type) list offers Three Bar Graph (Bar) and Ticker.
7. Choose Three Bar Graph (saved), go to My Claims Queue, verify one three-bar-graph tile in the ribbon and, in its information dialog, Style = "Bar Chart"; close the dialog.
8. Go back to the group, select the KPI, choose Ticker (saved), go to My Claims Queue, verify one ticker tile and Style = "Ticker" in its information dialog; close the dialog.

Notes:
- Test case wording follows the FRD; in the build Claim KPIs / CS KPIs are the Claims Processing KPIs / Customer Service KPIs headings, Period measured is Time Period, Style is Display Type (Three Bar Graph = Bar) and every change in the KPI editor is saved as it is made (no Save button).
- Shared helpers: utils/kpi.ts. After the test the user is taken out of the group again (afterEach), so the next test's ribbon only shows its own KPIs.
