# TC6295 - QC Orion - Create a Queue, Enable it and View in My Claims Queue

Categories: Smoke, Queue, Claims, Administration

1. Log in to Orion and go to Administration > Queues.
2. Click Add Queue, enter the queue name and description, and save (the test waits for the save to complete and keeps the new queue's id).
3. Sort the grid by ID descending, find the new queue (a new queue starts disabled, so its row offers Enable) and click Enable. The row now offers Disable.
4. Open the queue by its id and verify the page is for the new queue.
5. Click Assignments and assign the queue to the logged in user, then close the panel.
6. Click Criteria, add a Claim Form Type criterion with the value Professional (the claims already in QC are professional claims), then close the panel.
7. Click Reload. The queue now holds claims.
8. Go to Claim Inventory Management > My Claims Queue.
9. Open the Queue filter drop down and verify the new queue name is displayed.

Why steps 5-7: the Queue filter only lists queues that are assigned to the logged in user and that hold claims. A queue that is merely enabled does not appear.
