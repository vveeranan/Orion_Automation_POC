# TC17084 - GroupKPIs_WhenNeverConfiguredKPIEnabled_ShouldOpenEditorWithNoDefaults

Release ORION 2025.2000.1 - RT-25957 (Group KPIs). Spec: tests/RT25957.spec.ts.

Categories: Regression, KPI, GroupKPIs, Administration, Claims, Configuration

Setup (Setups/TC17084.cs): creates the group the test configures its KPIs on (Orion Worker Portal DLL: Groups.CreateGroup, read-or-create by name). The group is new, so no KPI was ever configured on it.

Steps in the test:

1. Log in to Orion.
2. Go to Administration > Groups, search for the group created by the setup and open it.
3. Open the Group KPIs tab.
4. Enable Claims Pending and select it to open the KPI editor.
5. Verify the editor shows the KPI name and has no Benchmark chosen, an empty Benchmark value and no Period measured chosen.
6. Verify the KPI is flagged "not configured!" in the list.

Notes:
- The FRD text says "the defaults will be filled in" but the test case (and the build) expect no defaults; the test follows the test case.
- Test case wording follows the FRD; in the build Claim KPIs / CS KPIs are the Claims Processing KPIs / Customer Service KPIs headings, Period measured is Time Period, Style is Display Type (Three Bar Graph = Bar) and every change in the KPI editor is saved as it is made (no Save button).
- Shared helpers: utils/kpi.ts. After the test the user is taken out of the group again (afterEach), so the next test's ribbon only shows its own KPIs.
