# TC6287 - QC Orion - Create a New Provider Ticket

Categories: Smoke, Provider, Ticket

1. Log in to Orion.
2. Go to Customer Service > My Tickets and note the ticket count.
3. Click Add Ticket, then click Provider Call. Unlike a Member Call, no ticket is created yet: the page stays on New Ticket and shows a provider search with the message "Provider is required."
4. Enter the caller and caller phone.
5. Search for the provider created by the setup and select the match. The ticket is created and opens in the Open status with the provider shown.
6. Go back to My Tickets and verify the new ticket is listed first (type Provider, status Open, the caller, created by the logged-in user) with the count up by one.
