# TC17096 - GroupKPIs_WhenUserWithoutKPIAccessSelectsEnabledKPI_ShouldShowConfigurationDetails

Release ORION 2025.2000.1 - RT-25957 (Group KPIs). Spec: tests/RT25957.spec.ts.

Categories: Regression, KPI, GroupKPIs, Administration, Permissions, Details

Setup (Setups/TC17096.cs): creates the group the test configures its KPIs on (Orion Worker Portal DLL: Groups.CreateGroup, read-or-create by name). Needs the user without KPI access from .env as for TC17095 (the test is skipped when it is not set).

Steps in the test:

1. Log in as the main automation user, open the group and its Group KPIs tab.
2. Enable Claims Pending with a complete configuration (More, value 4, Current Month, Ticker).
3. In a second browser session log in as the user without KPI access, open the same group and its Group KPIs tab.
4. Select the enabled KPI.
5. Verify the configuration details are shown: the KPI name and description, Benchmark More, value 4 and Current Month.

Notes:
- Test case wording follows the FRD; in the build Claim KPIs / CS KPIs are the Claims Processing KPIs / Customer Service KPIs headings, Period measured is Time Period, Style is Display Type (Three Bar Graph = Bar) and every change in the KPI editor is saved as it is made (no Save button).
- Shared helpers: utils/kpi.ts. After the test the user is taken out of the group again (afterEach), so the next test's ribbon only shows its own KPIs.
