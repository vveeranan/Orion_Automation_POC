# TC17090 - GroupKPIs_WhenEnabledKPISelected_ShouldShowConfigurationAndCurrentValues

Release ORION 2025.2000.1 - RT-25957 (Group KPIs). Spec: tests/RT25957.spec.ts.

Categories: Regression, KPI, GroupKPIs, Administration, Claims, Details

Setup (Setups/TC17090.cs): creates the group the test configures its KPIs on (Orion Worker Portal DLL: Groups.CreateGroup, read-or-create by name).

Steps in the test:

1. Log in to Orion.
2. Go to Administration > Groups, search for the group created by the setup and open it.
3. On Group Assignments click the logged in user in the Users list to assign them to the group (an afterEach clean-up takes them out again).
4. Open the Group KPIs tab.
5. Enable Claims Pending and set Benchmark More, the Benchmark value, Period measured (Time Period) and Style (Display Type); each change is saved as it is made. (More, value 6, Current Week, Ticker)
6. Reload the group, open Group KPIs and select the KPI.
7. Verify the details show the KPI name, its description, Benchmark More, value 6 and Current Week.
8. Go to My Claims Queue, open the KPI tile and verify its information dialog shows the Name, a numeric Individual and Group Average (current values), Benchmark containing 6 and a week Period Measured; close the dialog.

Notes:
- Test case wording follows the FRD; in the build Claim KPIs / CS KPIs are the Claims Processing KPIs / Customer Service KPIs headings, Period measured is Time Period, Style is Display Type (Three Bar Graph = Bar) and every change in the KPI editor is saved as it is made (no Save button).
- Shared helpers: utils/kpi.ts. After the test the user is taken out of the group again (afterEach), so the next test's ribbon only shows its own KPIs.
