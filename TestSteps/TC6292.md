# TC6292 - QC Orion - Create a New Provider Ticket Task

Categories: Smoke, Provider, Ticket, Task

1. Log in to Orion.
2. Go to Administration > Tasks and note the task count.
3. Go to Customer Service > My Tickets, click Add Ticket, then click Provider Call. No ticket is created yet: the page stays on New Ticket and shows a provider search.
4. Enter the caller and caller phone.
5. Search for the provider created by the setup and select the match. The ticket is created and opens in the Open status with the provider shown.
6. Open the Tasks tab and verify the ticket has no tasks (count 0, "No Tasks").
7. Click Add Task, enter the task title (the task is created as soon as the title is entered) and the task description.
8. Verify the Tasks tab now shows 1 task.
9. Close the task form and verify the task is listed in the Tasks tab by its title.
10. Go to Administration > Tasks and verify the task count is up by one.
