# TC6289 - QC Orion - Create a New Queue

Categories: Smoke, Queue, Administration

1. Log in to Orion.
2. Go to Administration > Queues and note the queue count.
3. Click Add Queue. The Queue dialog opens.
4. Enter the queue name and description, then click Save (the test waits for the save request to complete).
5. Verify the dialog closes and the queue count is up by one.
6. Set the grid to 20 per page (it shows 10 per page by default and its search box does not filter) and verify the new queue is listed with its name, description and a count of 0. A queue created from the UI starts disabled, so the row offers Enable and Delete.
